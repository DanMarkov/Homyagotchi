# 🐹 Хомягочи

Цифровой помощник в форме интерактивного тамагочи: через игру формирует устойчивые привычки — цифровую безопасность, софтскиллы, психогигиену.

**Демо:** https://danmarkov.github.io/Homyagotchi/

## Возможности MVP-демо

- Хомяк с показателями: здоровье, цифровая защита, настроение;
- Случайные события-ловушки (фишинг, мошенничество, информационная гигиена) — спасай питомца и учись;
- Уровни, монетки, ежедневная серия (streak);
- Прогресс сохраняется в браузере (localStorage).

## 🧩 Open-core модель (Apache 2.0)

Весь проект (движок, базовые механики, обучающие сценарии) публикуется под лицензией **Apache 2.0** (см. [`LICENSE`](LICENSE)). Школы, колледжи, университеты и библиотеки могут свободно создавать собственные версии игры без лицензионных платежей. Ценность продукта — не в коде, а в **постоянно актуализируемом контенте** (актуальные схемы мошенничества по данным Банка России), сервисе и экспертизе.

## 💼 Бизнес-модель

- **B2C**: бесплатная базовая версия + подписка на расширенные сценарии.
- **B2B**: брендированные версии под бренд партнёра, корпоративная аналитика, поддержка.
- **B2G**: интеграция в государственные программы цифровой грамотности.
- **B2B2C** (основной канал в перспективе): партнёрства с операторами связи (темы SMS-фишинга и подмены SIM-карт), банками и страховыми компаниями (антифрод-просвещение клиентов), социальными платформами и образовательными организациями. Открытость ядра позволяет банкам и операторам аудировать код без vendor lock-in.

## 👥 Аудитория (опрос, 37 студентов, 2026)

- главные страхи респондентов: потеря денег, взлом аккаунтов, утечка данных;
- **59,5 %** готовы уделять обучению 10–15 минут в неделю;
- **84 %** выбирают короткие форматы;
- **32,4 %** отметили геймификацию как мотиватор.

Эти данные определили мобильный формат и короткие игровые сессии (2–5 минут). Сценарии персонализируются под выбранную аудиторию (школьник / студент / взрослый) — экран выбора при первом запуске, поле `aud` у событий в `content/content.json`.

## 🎮 Игровая механика (по статье)

- виртуальный хомяк **Хори** попадает в типовые ловушки мошенников: фишинговое письмо, поддельный сайт, звонок «из банка», SMS «для верификации";
- игрок спасает питомца за **25–30 секунд** и получает разбор ошибки + как распознать угрозу в жизни;
- петля вовлечённости: случайные события, награды (монеты, XP) и штрафы за ошибки, ежедневная серия (streak), push-уведомления о состоянии питомца (кнопка в «Настройках»);
- компоненты геймификации: **очки (KP), уровни, предметы/аватары, рейтинг** кибербезопасности — доля верных ответов со званиями от «Новичка» до «Мастера киберзащиты» (раздел «Статистика»).

## 📊 Целевые метрики MVP

- **удержание (retention)**: не менее 50 % пользователей возвращаются в игру еженедельно через месяц;
- **обучаемость**: рост доли верных решений с 60 % до 90 % за четыре недели;
- **NPS** (индекс готовности рекомендовать): не ниже 40.

Метрика обучаемости встроена в приложение: «Рейтинг кибербезопасности» в разделе «Статистика» показывает текущий процент верных ответов и прогресс до следующего звания.

## Архитектура (v2)

Модульный ES-код без сборки — работает как статика на GitHub Pages:

```
content/            # контент как данные (для нетехнических редакторов)
  content.json      # события, привычки, советы, mood-сообщения, grounding
  lessons.json      # курсы и уроки (сцены → вопрос → объяснение → XP)
  *.js              # JSON, обёрнутый в window.__*__ для загрузки без сборки
src/
  core/             # чистая игровая логика (тестируется без DOM)
    store.js        # стор + версионированные миграции сохранений (v1 → v2)
    pet.js          # FSM питомца: idle/eating/jumping/sleeping/sick/happy + тики
    game.js         # экономика, привычки, события, серии, дневная цель XP
    lessons.js      # прогресс уроков и курсов
  render/
    engine.js       # пиксель-примитивы + пререндер спрайтов в offscreen-canvas
    sprites.js      # спрайты комнаты и хомяка (рисовка один раз, потом блит)
    scene.js        # RoomScene: слои, RAF 60fps, hover-подсветка, частицы
  ui/
    app.js          # DOM-обвязка, вкладки, магазин, события
    lessons.js      # дуолинго-плеер уроков
    support.js      # график настроения за неделю, дыхание 4-4-6, grounding 5-4-3-2-1
tests/              # unit-тесты (node:test): стор/миграции, FSM, экономика, уроки
.github/workflows/ci.yml  # CI: syntax check → тесты → валидация контента
```

### Запуск тестов

```
node --test "tests/*.test.js"
```

### Добавление контента без кода

Редактируй `content/content.json` (события, советы) или `content/lessons.json` (уроки) — затем `node tools/build-content.js` перегенерирует JS-обёртки.

## ☁️ Облачная синхронизация (Supabase)

Игра работает локально (localStorage). Опционально — синхронизация прогресса через Supabase:

1. Создай проект на [supabase.com](https://supabase.com)
2. В SQL Editor выполни `supabase/schema.sql` (таблица `saves` + RLS: каждый видит только своё)
3. В Settings → Actions добавь **Variables** для репозитория:
   - `SUPABASE_URL` = `https://<project>.supabase.co`
   - `SUPABASE_ANON_KEY` = anon public key
4. В Settings → Pages переключи Source на **GitHub Actions**
5. Push в `main` — workflow `deploy-pages.yml` соберёт `content/config.js` и задеплоит сайт

Без ключей игра полностью работает локально; панель покажет «синхронизация не настроена».

**Безопасность:** anon-ключ публичный по дизайну, доступ к чужим данным закрыт через RLS (`auth.uid() = user_id`). service_role-ключ нигде не используется.
